# WorkBuddy Theme Manager 变现方案

> 方案讨论稿。当前仅讨论，未实施任何改动。

## 核心判断

项目当前是「免费工具」形态，变现最自然的锚点是主题内容，而不是工具本身。守护、恢复、从图片生成如果收费会削弱产品吸引力；真正能收钱的是「比用户自己生成更漂亮、更有设计感的主题」和「省事的 Pro 能力」。

关键约束：当前主题能力只有「配色 + 背景图」，没有布局、导航、卡片结构定制。付费主题的溢价来源目前只能是「精心设计的背景图 + 配色组合」。要么补设计内容，要么扩展主题能力。

## 现状盘点

目标用户：WorkBuddy 的非技术用户，愿为「好看、省事」付费，但不愿折腾。

已有资产：

- 本机取色生成主题
- CDP 应用 / 守护 / 恢复
- 跨平台（macOS / Windows）
- 预置主题画廊框架
- WorkBuddy 版本与安装位置检测

缺失能力：

- 账号体系
- 后端服务
- 支付接入
- 付费主题内容储备
- 官网 / 下载分发
- 自动更新

## 三种变现模式对比

| 模式 | 收入形态 | 需要投入 | 适合阶段 |
| --- | --- | --- | --- |
| 内容付费（主题商店） | 单款主题 / 主题包收费 | 设计内容 + 支付 + 分发 | 最早、最轻 |
| Pro 订阅 / 买断 | 解锁高级功能 | 额外开发功能 + 账号 / 支付 | 中期 |
| 社区投稿 + 分成 | 平台抽成 | 后端 + 审核 + 创作者体系 | 远期 |

三者不互斥。建议当前走「内容付费先行，Pro 随后」的轻路线。

## 推荐路径

### 第一步：零后端买断 + 激活码

预置画廊分「免费款 / 付费款」。付费款通过电商平台收款，用户拿到激活码在客户端解锁，本地校验，不建服务器。

目标：最快落地，验证「有没有人愿意为主题付钱」。

### 第二步：轻后端 + 订阅 / 主题商店

验证付费意愿后，引入 Supabase + Paddle / Stripe，做账号、主题商店、授权校验、自动更新。付费主题与 Pro 能力都挂在这一层。

### 第三步：社区投稿 + 分成

有稳定用户量后再考虑，参考 codex-themes 的投稿、审核、积分、创作者分成模式。当前不碰。

## 第一步细化：零后端买断 + 激活码

### 目标与验收标准

目标：用最少改动跑通「下载 → 看到付费主题 → 付款 → 拿激活码 → 解锁 → 应用」，验证是否有人愿意为 WorkBuddy 主题付费。

验收标准：

- 至少 1 款付费主题 + 若干免费主题可展示
- 用户能完成一次真实支付并拿到激活码
- 客户端能校验激活码并解锁主题
- 解锁状态持久化，重启后仍有效
- 付费主题能正常应用、守护、恢复

### 产品流程

画廊分两类：

- 免费主题：正常「安装并应用」
- 付费主题：卡片显示价格 + 锁定标记，点击进入「购买 / 解锁」

推荐购买流程（Lemon Squeezy License Key）：

1. 画廊点付费主题 → 显示价格与「购买」
2. 跳转浏览器 Lemon Squeezy 结账页
3. 支付成功自动发 License Key（邮件 / 结账页）
4. 回客户端粘贴激活码 → 调用 Lemon Squeezy License API 激活
5. 激活成功本地缓存授权并解锁主题

首发极简备选（纯离线）：

- 本地脚本批量生成签名激活码，手动导入电商平台 / 淘宝发货
- 客户端内置公钥离线校验，不联网
- 优点：不依赖第三方激活 API；缺点：发码手动、无法撤销

### 主题内容生产

- 免费款 2–3 款引流
- 付费款 6–10 款，做成主题套装或单款
- 背景图：纯背景 / 插画 / 纹理，不含 UI 和文字
- preview.png：可带界面效果，用于画廊预览
- 来源：自己设计 / imagegen 生成 + 人工配色 / 外包

### 技术改造清单

前端：

- 主题卡片增加「付费 / 价格 / 锁定 / 已解锁」状态
- 新增购买与解锁流程：价格、购买外链、激活码输入、解锁
- 若走独立分发，新增「导入付费主题包」入口
- 解锁状态本地持久化

后端：

- 新增 command：查询授权状态、激活、撤销
- 授权状态存 app data 目录 licenses.json（原子写）
- 激活码校验：Lemon Squeezy License API（推荐）或内置公钥 Ed25519 签名（极简）
- 付费标记：manifest 增加 paid / price 字段，或独立付费主题清单
- 独立分发可复用现有 `.wbskin` 导入逻辑

安全（防君子不防小人）：

- 私钥只留在生成端，客户端只放公钥
- 授权缓存可绑定设备标识，首发不强求
- 纯离线方案可被逆向，对非技术目标用户够用

### 支付与交付

- Lemon Squeezy 建 product，开启 License Key 自动发码
- 客户端结账用 checkout URL
- 纯离线则 CSV 批量导入预生成激活码
- 备选：Paddle（能力类似）、国内爱发电 / 面包多 / 淘宝自动发货

### 里程碑与任务拆分

- M1 内容 + 主题包：验收 preset-themes 可列出主题，图片配色正常
- M2 付费标记与锁定 UI：验收画廊区分免费 / 付费，付费锁定
- M3 激活码校验 + 解锁持久化：验收有效码解锁、重启有效、无效码报错
- M4 支付 + 发码闭环：验收真实购买后拿到码可解锁
- M5 端到端验证：验收全流程跑通

### 风险与验证指标

- 风险：破解、WorkBuddy 升级失效、付费主题不够好看
- 指标：免费安装量、购买点击转化率、解锁数 / 收入、退款率
- 判定：M5 跑通后 2–4 周付费解锁为 0 或转化极低，说明付费理由不足，先补内容或转 Pro，不上后端

## 嵌入点（对应现有界面）

免费区（留住用户）：

- 从图片生成
- 主题守护
- 恢复官方外观
- 基础主题

付费区：

- 主题画廊：卡片加「免费 / 价格」标签，付费卡片进解锁流程

未来 Pro 能力（现均未实现，作为收费功能开发）：

- 高级取色 / 精修
- 主题微调编辑器
- 多主题轮换
- 批量生成

不要在「守护 / 恢复」上设卡，那是产品的信任基础。

## 支付与分发渠道

出海：

- Paddle / Lemon Squeezy：处理全球税务与合规，适合个人 / 小团队，无需自建商户主体。
- Stripe：体验好，但需要公司主体。
- 激活码本地校验最省事但可被破解；轻后端阶段再换 License 服务。

国内：

- 爱发电、面包多、淘宝自动发货，配合激活码，零开发成本冷启动。

## 定价参考

- 单款付费主题：0.99–4.99 美元
- 主题包（5–8 款）：9.9–19.9 美元
- Pro 订阅：3.99–9.99 美元 / 月
- Pro 买断：19.99–39.99 美元
- 先用免费或极低价款引流，测转化率后再定正式价

## 自有优势

运营侧有公众号、知乎等自媒体渠道，可用「WorkBuddy 美化教程 + 免费主题赠送」内容获客，把读者导到下载页。这是相对纯开发者的冷启动优势。

## 风险与前提

1. 平台依赖：主题靠 CDP 注入，WorkBuddy 升级可能使选择器失效。付费用户遇到失效会很伤，自动更新与兼容修复必须跟上。
2. 内容生产力：付费主题必须真有设计感，否则「用户自己传图就行」。这是最大短板。
3. 别急着上后端：先用激活码验证付费意愿，再投入账号 / 支付。

## 落地建议（优先级）

1. 出 6–10 款有设计感的付费主题 + 免费款。
2. 用 Lemon Squeezy / Paddle + 激活码跑通「下载 → 付费 → 解锁 → 应用」闭环。
3. 验证后再上 Pro 与后端。

## 待补充信息

WorkBuddy 的用户规模和付费习惯尚未确认，会直接影响「低单价走量」还是「高客单服务」的选择。确认后再收窄定价与渠道。
