# 预置主题文生图提示词

这 6 个提示词对应「主题画廊」的 6 个预置主题，是当前内置背景图的生成记录，也可用于后续重新生成同方向素材。

## 使用方式

1. 使用 16:9 横向构图，主体放在画面边缘，中央保留低细节区域供 WorkBuddy 内容覆盖。
2. 生成结果必须清晰、无文字、无界面元素，并通过项目的图片格式、尺寸和体积校验。
3. 图片命名为 `background.png`，放进对应主题目录的 `assets/` 下。
